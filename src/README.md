# Исходный код

Проект состоит из трёх платформенных компонентов:

| Компонент | Платформа | Описание |
| --- | --- | --- |
| `core/` | Rust (lib) | Акустический кодер/декодер, FEC, протокол передачи |
| `cli/` | Rust (bin) | Терминальный клиент и диагностические утилиты |
| `mobile/` | Flutter + Rust | Мобильное приложение (Android/iOS) |

## Инструкция по запуску и сборке

### Терминальный клиент

```bash
# из корня репозитория
cargo run -p sonic-share-cli
```

### Мобильное приложение

```bash
cd src/mobile
flutter pub get
flutter run
```
