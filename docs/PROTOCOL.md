# Спецификация акустического протокола

## Цели

Обеспечить надёжную передачу файлов и коротких текстовых сообщений между устройствами через акустический канал без использования радиомодулей (Wi-Fi, Bluetooth, NFC).

## Физический уровень

- **Частота дискретизации**: 48 кГц.
- **Разрядность**: 16 бит, моно.
- **Амплитуда**: 0.6 (float PCM).

### FSK

- 2-FSK (Fast: ~180 бит/с, Robust: ~90 бит/с) и 4-FSK.
- Используется для манифестов и в режиме совместимости.

### OFDM

- 1024-точечное БПФ, 64 информационных несущих + 8 пилотных.
- Дифференциальная модуляция: DBPSK (safe), QPSK (fast), QAM16.
- Циклический префикс: 384 отсчёта.
- Скорость: ~200–550 бит/с в зависимости от созвездия.
- Частотное разнесение: rep-2, rep-3, rep-4 (по умолчанию rep-4 DBPSK).

## Формат передачи

1. **Манифест**: метаданные передачи (имя файла, размер, SHA-256, число групп).
2. **Группы данных**: 8 пакетов данных + до 4 пакетов RS-чётности на группу.
3. **End packet**: завершающий пакет.

Манифест пересылается каждые 3 группы для устойчивости к пропускам.

## Установление и завершение передачи

Передатчик начинает с манифеста. Приёмник обнаруживает манифест через гибридный детектор (FSK или OFDM) и переходит в соответствующий режим. Завершение — по end packet или таймауту.

## Синхронизация

OFDM: дифференциальная модуляция по времени, что устраняет статический фазовый сдвиг канала и фиксированное смещение дискретизации. Заголовок — дифференциальный rep-4 с временной избыточностью для надёжного обнаружения.

## Ошибки и восстановление

- **Reed-Solomon**: RS(223,255) для FSK, RS(191,255) для OFDM. Настраиваемое число символов чётности.
- **Перемежение**: канальное перемежение для защиты от пакетных ошибок.
- **SHA-256**: проверка целостности после полного приёма файла.

## Совместимость

Передатчик и приёмник должны работать на одинаковой частоте дискретизации (48 кГц). Разные пары в одном помещении должны использовать разные частотные полосы (lane).

## Пример

```bash
# Отправка файла с режимом OFDM safe (по умолчанию)
cargo run -p sonic-share-cli --bin send -- file example.bin

# Приём
cargo run -p sonic-share-cli --bin listen
```
