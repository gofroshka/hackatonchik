# Методика и результаты тестирования

## Методика

Тестирование проводится в несколько этапов:

1. **Регрессионное тестирование** — без звукового тракта, проверка кодирования/декодирования, FEC и SHA-256.
2. **Физическое тестирование** — передача через динамик и микрофон (loopback на MacBook Air, а также между разными устройствами).
3. **Тестирование помехоустойчивости** — с аддитивным шумом, затуханием и многолучёвостью.
4. **Одновременная работа** — несколько пар на разных частотных полосах (lane).

Подробные сценарии тестирования описаны в [acceptance-tests.md](acceptance-tests.md).
