# Архитектура решения

## Контекст

Sonic Share — система передачи файлов и текстовых сообщений между устройствами через акустический канал (динамик → микрофон). Не требует Wi-Fi, Bluetooth или мобильной сети.

## Основные технические решения

- **Физический уровень**: FSK (2-FSK, 4-FSK) и OFDM (1024-FFT, 64 несущих данных + 8 пилотных, дифференциальная модуляция DBPSK/QPSK/QAM16).
- **FEC**: Reed-Solomon с настраиваемым числом символов чётности, перемежение.
- **Сжатие**: zstd (сжатие перед отправкой, распаковка после приёма).
- **Контроль целостности**: SHA-256 на каждый файл.
- **Протокол передачи**: манифест → группа данных (8 данных + до 4 RS чётности) → end packet. Текстовые пакеты для чата.
- **Детектор**: гибридный — слушает эфир, определяет FSK или OFDM по синхросигналу.

## Зависимости

- **Rust**: cpal (аудиоввод/вывод), rustfft (OFDM), reed-solomon (FEC), sha2, zstd, ratatui/crossterm (TUI).
- **Flutter**: flutter_rust_bridge 2.12, flutter_sound (аудио), file_picker, permission_handler, wakelock_plus.

## Безопасность и приватность

- Все данные передаются в открытом виде (нет шифрования).
- Передача только в пределах слышимости (физическая изоляция).
- SHA-256 только для проверки целостности, не для аутентификации.
